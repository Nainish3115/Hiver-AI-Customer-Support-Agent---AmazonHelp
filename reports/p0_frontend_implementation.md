## 1. Frontend Architecture

The frontend is built as an independent React + TypeScript + Vite + Tailwind CSS Single Page Application (SPA) located under `frontend/`. It communicates directly with the FastAPI REST API (`http://localhost:8000/api/v1`) via a strongly typed API client layer (`src/api/client.ts`).

├── tailwind.config.js           # Custom dark theme tokens & shadow utilities
├── tsconfig.json                # TypeScript strict configuration & alias path
├── vite.config.ts               # Vite bundler & API dev proxy configuration
└── src/
    ├── api/

## 2. Design System

The visual language follows a recruiter-focused AI SaaS aesthetic:

- **Background**: Deep Navy / Charcoal (`#0B0F19`) with subtle radial glow backdrops (`bg-glow-radial`).
- **Accent Lighting**: Violet (`#8B5CF6`), Magenta (`#EC4899`), Cyan (`#06B6D4`), Emerald (`#10B981`), Amber (`#F59E0B`).
- **Glassmorphic Cards**: Translucent surfaces (`rgba(19, 26, 42, 0.7)`), 12px backdrop blur (`backdrop-blur-md`), fine borders (`rgba(255, 255, 255, 0.08)`).
- **Typography**: Clean sans-serif via **Inter** font family with strong heading hierarchy and monospaced code elements.
- **Buttons & Chips**: Gradient buttons with violet/pink glow effects (`shadow-glow-violet`), subtle hover state transitions (`glass-panel-hover`).

## 4. Live Support Demo Workspace

The `LiveDemo.tsx` workspace renders real API response fields returned by `CustomerSupportPipeline`:

- **Intent Card**: Predicted intent name, confidence percentage badge (e.g. `85.0%`), decision source metadata.
- **Retrieval Card**: Number of formatted evidence items, retrieved case ID chips (`RAG-AMAZON-669198`, etc.), similarity score chips.
- **AI Response Card**: Grounded draft response generated by **Gemini 1.5 Flash**, Grounding status badge (`GROUNDED` in green), Safety status badge (`PASS` in green).
- **Decision Card**:
  - `AUTO_HANDLE`: Prominent green glow banner, *"Safe Automated Response"* rationale.
  - `ESCALATE_TO_HUMAN`: Prominent amber glow banner, *"Human Escalation Required"* rationale.
  - **Composite Risk Gauge Bar**: Visual progress indicator showing composite risk relative to the $0.3500$ threshold.
  - **Reason Code**: Trigger code (e.g. `SAFE_AUTO_HANDLE` or `COMPOSITE_RISK_EXCEEDED`).

## 5. API Integration

`src/api/client.ts` implements typed REST integration using `fetch`:

```typescript
export async function processSupportMessage(req: SupportProcessRequest): Promise<SupportProcessResponse>
export async function checkHealth(): Promise<HealthResponse>
export async function fetchProjectStats(): Promise<StatsResponse>
export async function searchRetrievalCorpus(query: string, topK?: number): Promise<RetrievalSearchResponse>
```

- **Base URL**: Configurable via `import.meta.env.VITE_API_BASE_URL` (defaults to `http://localhost:8000/api/v1`).
- **Error Handling**: Custom `ApiError` class captures HTTP error status codes and API error detail JSON.
- **Status Indicator**: Navbar regularly pings `GET /api/v1/health` and displays a live green indicator when the backend server is online.
